# Release 3.2.0 — `@xylex-group/athena`

Consumer-optimization release for heavy Next apps (e.g. speedrun-formations).

## Install

```bash
pnpm add @xylex-group/athena@3.2.0
```

## What’s new

| Area | Summary |
| --- | --- |
| **Server `scope`** | `createAthenaServerClient({ scope: { userId, organizationId } })` applies gateway identity headers without empty `withContext({})`. Dev warnings for empty scope / empty context. |
| **`getServerSession`** | `@xylex-group/athena/next/server` — middleware header → get-session fetch → product `resolveActiveOrganizationId` → optional ensure-active. |
| **`@xylex-group/athena/env`** | Primary keys `ATHENA_URL`, `ATHENA_API_KEY`, `ATHENA_CLIENT`, `ATHENA_AUTH_URL`; `legacyAliases: true` for historical multi-key sets. |
| **Admin credentials** | `buildAdminAuthFetchOptions` + `credentials` on `hasAdminPermission` / `resolveAdminPermission`. |
| **Sign-out lifecycle** | `signOutAndClearAthenaSession` (signOut + clear cookies + optional bridge + hard redirect). |
| **Diagnostics** | `diagnostics: 'auto' \| boolean` — quiet in production / OpenNext build; per-flag overrides still win. |

## Upgrade checklist (consumer)

1. Pass `scope` / `session` into `createAthenaServerClient` (replace no-op scoped helpers).
2. Shrink app `get-session` to product org policy + `getServerSession`.
3. Replace multi-key env resolvers with `requireAthenaEnv` / `resolveAthenaEnv`.
4. Admin gates: `credentials: { cookie }` instead of prefix string matching.
5. Sign-out: `signOutAndClearAthenaSession` + optional session bridge clear.
6. Prefer `diagnostics: 'auto'` instead of OpenNext-specific branching.
