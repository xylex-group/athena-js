# Auth Social and Provider Accounts

Public SDK: `athena.auth.social.*`, `athena.auth.account.*`, `athena.auth.callback.provider`.
There is no `athena.oauth` / `createOAuthClient`.

The separate Embedded Authorization Server admin surface is
`athena.auth.admin.authorizationServer.client` and `.grant`; it manages
applications that use Athena as issuer. It does not configure upstream social
providers or dedicated Rust callback allowlists. See
[`auth.admin.authorizationServer`](./admin.mdx#authorization-server-clients-and-grants).

Embedded local: `createClient({ auth: { social: { providers: { google, github, … } } } })`
is accepted and normalized ([ADR 0050](../../../../docs/adr/technical/0050-athena-js-social-oauth-orchestration.md)).
`auth.social.providers` configures application-level social providers such as
Google and GitHub. Organization-owned enterprise OIDC connections use
`auth.admin.connection` and are stored separately. They support domain routing,
an optional SSO-required policy, and just-in-time organization membership.
Confidential connections keep secrets outside the connection record: provide
an opaque `credentialRef` and resolve it with
`resolveIdentityConnectionCredential` in the Embedded Auth runtime options.

## Endpoints and methods

- `auth.social.link()` -> `POST /link-social`
- `auth.account.list()` -> `GET /list-accounts`
- `auth.account.unlink()` -> `POST /unlink-account`
- `auth.deleteUser.callback()` -> `GET /delete-user/callback`
- `auth.refreshToken()` -> `POST /refresh-token`
- `auth.getAccessToken()` -> `POST /get-access-token`
- `auth.health()` -> `GET /health` (fallback to `GET /ok` on `404`)
- `auth.ok()` -> `GET /ok`
- `auth.error()` -> `GET /error`

## Examples

```ts
import { client } from "./auth-client"

await client.auth.social.link({
  provider: "google",
  callbackURL: "https://app.example.com/auth/callback",
})

await client.auth.account.list()

await client.auth.account.unlink({
  providerId: "google",
  accountId: "acc_123",
})

await client.auth.deleteUser.callback({
  token: "delete_callback_token",
  callbackURL: "https://app.example.com/delete-callback",
})

await client.auth.refreshToken({
  providerId: "google",
  accountId: "acc_123",
  userId: "usr_123",
})

await client.auth.getAccessToken({
  providerId: "google",
  accountId: "acc_123",
  userId: "usr_123",
})

await client.auth.health()
await client.auth.ok()
await client.auth.error()
```
