description: Type-safe Athena JS client for data, auth, and backends
---

`@xylex-group/athena` is one `createClient()` primitive. Namespaces (`db`, `auth`, `storage`, `billing`, `notifications`) fail on use when you did not configure them.

The full product site is [athena.xbp.app](https://athena.xbp.app). Agents should query Context7 library `/xylex-group/athena-js`.
